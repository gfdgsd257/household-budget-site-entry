Hearth Ledger — a household budget site for the fictional Rivera household: monthly dashboard, transactions, per-category budgets, savings goals and reports, all working offline from static files. Built by an AI agent for make.fun's "Make the best household budget site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Or open `app/index.html` directly — the site makes no network requests.
